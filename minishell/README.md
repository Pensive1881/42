# MINISHELL

## Description


## Instructions
### Compile

```zsh
make
```

### Run minishell

```zsh
./minishell
```

### Clean object files

```zsh
make clean
```

### Remove object files and executable

```zsh
make fclean
```

### Recompile everything

```zsh
make re
```

### Example Usage

```shell
minishell$ echo hello world
hello world

minishell$ ls -l | grep minishell

minishell$ export USERNAME=marvin

minishell$ echo $USERNAME
marvin
```

### Supported Features

```md
- pipes (`|`)
- redirections (`<`, `>`, `>>`)
- heredocs (`<<`)
- environment variables (`$VAR`)
- signal handling
- builtins
```
